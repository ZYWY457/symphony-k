# Exec Plans

Use Exec Plans for substantial multi-step work.

Each plan should contain:

- objective,
- context,
- architecture constraints,
- in scope,
- out of scope,
- milestones,
- dependencies,
- risks,
- acceptance criteria,
- evidence required for completion,
- decisions or ADR references.

Active plans live in `active/`. Move completed plans to `completed/` without rewriting their history.
